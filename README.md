# Portafolio — Miguel Rodriguez

Sitio web de portafolio personal desarrollado para Miguel Rodriguez, estudiante de Diseño Gráfico en Bogotá, Colombia. El proyecto presenta su trabajo creativo en distintas áreas del diseño a través de una experiencia visual dinámica e interactiva.

## Sobre el proyecto

El portafolio fue construido desde cero con HTML, CSS y JavaScript vanilla, sin frameworks ni dependencias externas. El diseño refleja la identidad visual de Miguel: tipografía bold, paleta de colores vibrante y animaciones que acompañan el scroll.

## Secciones

- **Hero** — Presentación principal con animación flotante y estrellas decorativas.
- **About Me** — Información sobre Miguel, sus skills, educación e intereses.
- **Dibujos** — Ilustraciones personales con animación de abanico.
- **Modelado y Animación 3D** — Proyectos en Cinema 4D: Deadpool LEGO, El Principito y Tren de Madera.
- **Diseño Editorial** — Revista Tricolor, propuesta editorial inspirada en Colombia.
- **Packaging** — Tres propuestas de empaque para Juan Valdez con interacción fan/grid.
- **Branding** — Proyectos de identidad visual: Ojito al Corto (festival de animación) y Son de Calle (festival de salsa).
- **Contacto** — Email, WhatsApp e Instagram.

## Tecnologías

- HTML5 semántico
- CSS3 (Grid, Flexbox, custom properties, animaciones)
- JavaScript vanilla (IntersectionObserver, requestAnimationFrame)
